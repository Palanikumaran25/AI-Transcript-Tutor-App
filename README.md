# 🎓 AI Transcript Powered Tutor App

## About the Project

The AI Transcript Powered Tutor App is an intelligent learning application that helps users understand YouTube educational videos more efficiently.

Instead of watching an entire video again to find important information, users can simply ask questions about the video and receive clear answers.

The application acts like a personal AI tutor, making learning faster, easier, and more interactive.

--- 

## 🚀 Features

- 📺 Extract transcripts from YouTube videos
- 📝 Automatic transcript processing
- ✂️ Intelligent text chunking
- 🔍 Semantic search using FAISS Vector Database
- 🤖 AI-powered Question & Answer system
- 🎤 Voice input support
- 🔊 Text-to-Speech (Speech Synthesis)
- 💬 Interactive Streamlit interface
- ⚡ Fast response using Retrieval-Augmented Generation (RAG)

---

## Why This Project?

Educational videos often contain valuable information, but finding a specific topic can take a lot of time.

This project solves that problem by allowing users to interact with the video through simple questions.

---

## What Can You Do?

- Paste a YouTube video link
